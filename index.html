Completing my coursework for my computer science program and developing my portfolio has been a beneficial and transformative experience as a beginner software engineer. This portfolio showcases the culmination of my technical strengths as it encompasses all that I’ve learned from my college career. From beginner programming courses that taught me foundational pillars that shaped my portfolio artifact, to the secure coding courses that allowed me to understand how to make a safe program that can be used without exploitation from bad actors. I have been educated on the software development lifestyle and have proven to understand these concepts as I have implemented a disciplined approach to each computer science class I have taken. I have learned how to develop object-oriented code as well as how to effectively test it for use cases so that it can be functional for a broad amount of end users. I can solve complex problems while delivering secure, optimized applications to showcase my dedication to best engineering practices.

I’ve come to learn that software development is a collaborative effort; across my academic journey I have found immense value in working with cross functional teams. Utilizing agile methodology, sprint planning, and code reviewing benefits team projects significantly and can dictate how smooth the development of an application can be. Merging codebases using Git, resolving merging conflicts, and task distribution are important concepts that I will carry with me into my future career. Team synergy can produce scalable and maintainable architectures that would prove significantly more difficult to obtain as a solo developer.

Throughout the program, I have developed the skills to translate complex technical terms into clear concepts for stakeholders. Stakeholders generally are not software engineers and require software documentation, presentations, and design prototypes that are comprehensive for them to communicate the product as effectively as possible. I have written documentation to prove that I can appeal to stakeholders using simple but effective terms to convey the purpose and progress of products. Dual lens communication can ensure that engineering choices are aligned with business requirements so that the stakeholders can stay informed and understand development trajectory.

One of the core strengths I refined was the implementation of optimal data structures and algorithms so that my developed software could run with efficiency. During my mobile application development, I replaced linear searches with highly effective data structures. I implemented hash maps such as idIndexMap alongside a dynamic list collection to achieve 0(1) time complexity for key-value record lookups. Implementations such as these can ensure that software engineered by me can minimize memory footprints and handle heavy runtime data loads seamlessly.

My training put an emphasis on clean code architecture, structural design patterns, and robust database management. This has allowed me to develop a command of relational database design, data normalization, and defensive CRUD operations. Applying software engineering principles such as the Singleton pattern to resource managers, I ensure thread safe and centralized control over system assets. My approach to these concepts focuses on modularity as well as readability and maintainability.

Security is a foundational element that I embedded within my development workflow as it is much more difficult and suboptimal to implement after an application is developed. Not only this, but I am dedicated to protecting user privacy and preventing vulnerabilities that can jeopardize not only users, but code integrity too. My practices include mitigating SQL injections through parameterized database queries, implementing strict data validation protocols, and enforcing dynamic runtime permission checks for hardware features while employing industry standard cryptographic hashing algorithms (such as BCrypt) to protect user credentials.

The centerpiece of my portfolio is my Android based mobile inventory tracking application called “TrakTrak”. This artifact represents a demonstration of my multi-faceted talents in computer science, as it shows my enhancement of a full stack application that is elevated to meet professional standards. The architecture of this application was modernized by introducing a Singleton pattern to manage the database connections across concurrent activities. I offloaded heavy disk I/O operations from the main UI thread to asynchronous background threads using single thread executors. The user interface was modularized using a custom InventoryAdapter and a reusable ViewHolder pattern to handle dynamic view lifecycle bindings. To optimize the data and UI synchronization, I integrated a dual layered collection strategy inside DataActivity. By pairing an ArrayList with a tracking HashMap, the application avoids redundant database queries when verifying item existence or retrieving records in memory. This creates a responsive and lag free user experience. The underlying data layer was hardened against modern threat vectors. In DataBase helper, manual string concatenation was replaced with parameterized SQLite queries and compiled ContentValues to block SQL injection attacks. Plaintext user authentication was replaced with stronger password security using BCrypt salting and hashing. Lastly, the external communication pathways in SmsActivity were locked down by enforcing runtime permission checks to protect user privacy and hardware resources. This artifact from my CS 360 mobile development course showcases a combined and complete software enhancement, demonstrating my ability to deliver safe, efficient, and improved software stions.
